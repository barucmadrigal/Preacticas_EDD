Como ejecutar la practica: 
Para ejecutar la practica, es necesario tener todos los archivos dentro de la misma carpeta, 
despues desde la terminal ejecutar el comando "javac *.java" para compilar todos los archivos .java, 
y despues para comprobar el funcionamiento de los algoritmos de ordenamiento, es necesario compilar  y ejecutar 
el archivo "MainOrdenamientos2.java", y para comprobar la resolucion del problema se compila y ejecuta el archivo
"Curso.java" que contiene el metodo main para resolver el problema de ordenamiento de cursos.
